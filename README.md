# Fling for macOS

**Instant Command Wheel for Mac.**
Hold a shortcut, flick toward an action, release.

- **Website**: [getfling.app](https://getfling.app)
- **Support**: [hi@getfling.app](mailto:hi@getfling.app)
- **Requirements**: Apple Silicon Mac (M1/M2/M3/M4) running macOS 14 (Sonoma) or macOS 15 (Sequoia) or later.

---

### Downloads

Download the latest version of Fling from the [Releases](https://github.com/VC067/fling-app/releases) page.

#### Installation
1. Download `Fling.dmg`.
2. Open `Fling.dmg` and drag **Fling** into your **Applications** folder.
3. Launch Fling from Applications.
